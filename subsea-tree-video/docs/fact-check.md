# Fact-check sheet (for the subject-matter expert)

The script was written from public web sources. Several primary documents (NORSOK D-010, company specifications,
supplier data books) could **not** be opened during the build — only search-result summaries and public pages were
available — so every statement below should be confirmed by an SME against current internal documentation before the
video is released. Where the video attributes a claim ("Aker Solutions says …") the wording is deliberately hedged.
